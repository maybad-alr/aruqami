# أرقامي — Aruqami

**الموقع:** https://maybad-alr.github.io/aruqami/

منصة عربية مجانية تقدم حاسبات مالية وعملية دقيقة: مكافأة نهاية الخدمة، الزكاة،
ضريبة القيمة المضافة، التمويل العقاري والسيارات، الرواتب، الصحة، المواريث،
محوّل العملات ومحوّل الوحدات.

## عن هذا المستودع

يحتوي هذا المستودع على ملفات الموقع الجاهزة التي يقدّمها GitHub Pages فقط
(HTML وCSS وJavaScript). أما الكود المصدري وأدوات التوليد وملفات المحتوى فتُدار
في مستودع خاص منفصل.

## من المزايا

- 17 حاسبة مبنية على الأنظمة والمراجع الرسمية
- وضع نهاري وليلي، وبحث فوري، وروابط قابلة للمشاركة
- جميع الحسابات تُنفَّذ داخل متصفح الزائر دون إرسال أي بيانات
- خريطة موقع وبيانات منظمة لتحسين الظهور في محركات البحث
